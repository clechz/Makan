# Mobile survey reference

The mobile homepage uses the user-approved Pix4D construction example: a drone orthomosaic and a rendered view of the corresponding 3D point cloud. These are still images, not an interactive mesh or two acquisition dates. They are not Makan detections.

Source and usage terms: https://support.pix4d.com/hc/en-us/articles/360000235126 (Construction dataset). The page permits promotional use with the linked credit “Courtesy of Pix4D / pix4d.com”; that credit appears alongside the mobile comparison.

- Overhead original: https://support.pix4d.com/hubfs/Knowledge%20Base%20Import/360011073832.png
- 3D original: https://support.pix4d.com/hubfs/Knowledge%20Base%20Import/360011104211.png

The original PNGs are retained as `survey-overhead-source.png` and `survey-3d-source.png`. The served WebP versions preserve the photographs, capped at 1000 pixels, quality 88. A static SVG filter makes the black presentation matte transparent over the existing sky. No traced boundaries, measurements or temporal changes are invented.
